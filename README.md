# 탐구분석지도

학교생활기록부 PDF를 올리면 세부능력 및 특기사항(세특)과 창의적 체험활동(창체)에 적힌 탐구가
어디서 시작해 어디로 이어졌는지 **한 장의 계보도**로 보여 주고, 학기별, 교과군별로 **어떤 탐구 방법을 썼고 무엇이 비어 있는지**를
측정하는 교사용 상담 도구입니다.

- 학생부는 선생님의 브라우저 안에서만 읽고 분석합니다. 서버, 클라우드, AI 서비스로 보내지 않습니다.
- 판단은 규칙과 어휘 사전으로 합니다. 모든 판정에는 근거 문장이 함께 나옵니다.
- 1학년 학생부만 있어도 동작합니다. 세특 초안을 직접 붙여 넣어 점검할 수도 있습니다.

참고: 박상근 선생님의 [모두의 탐구의 맥](https://park-sanggeun-all.github.io/tamgu-maek/)(사용 설명서 발행: 모두의진학, 2026년 10월판)을 참고했습니다.

- 알고리즘(셀 기반 PDF 파서, 사전 기반 방법 탐지, 4단계 깊이, 낱말 공유 기반 연결, 연결 종류 판정)을 참고하여 TypeScript로 새로 구현했습니다.
- 분류 체계는 참고 앱을 그대로 따랐습니다: 탐구 방법 17종의 이름과 3수준 배정, 깊이 4단계 가운데 1, 2, 4단계 이름(정리·참여, 조사·분석, 성찰·확장),
  연결 종류 이름(심화, 확장, 전환, 반복, 같은 시기), 화면 용어(탐구 계보도, 추가 탐구, 관심 주제, 표현 사전, 상담 노트).
- 표현 사전(방법, 과학 탐구 기능, 관심 분야를 찾는 정규식 어휘)은 복제하지 않고 자체 작성했습니다.
- 참고 앱의 이용 조건(라이선스)은 공개된 자료에서 확인하지 못했습니다. 이 도구를 널리 배포하기 전에 만드신 분께 확인해 주세요.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 첫 화면 | 학생부 PDF 올리기(여러 파일, 끌어다 놓기, 한 반 묶음 PDF는 학생별로 나눔), 예시 학생 보기, **직접 입력**, 작업 파일(.json) 불러오기 |
| 직접 입력 | PDF 없이 학년, 학기, 세특/창체, 과목 또는 영역, 성취도, 등급, 본문을 항목별로 붙여 넣어 바로 분석합니다. 세특 초안 점검에 씁니다. |
| 탐구 계보도 | 가로 학기, 세로 창체와 교과군. 카드 하나가 기록 하나. 연결선마다 심화, 확장, 전환, 반복, 같은 시기 가운데 무엇인지와 연결 이유(공통 낱말, 직접 언급, 방법 변화, 깊이 변화)를 보여 줍니다. 카드를 누르면 그 기록의 계보만 밝게 보이고 상세 창이 열립니다. |
| 기록 상세 창 | 원문(방법 표현, 관심 주제, 과학 탐구 기능 형광펜), 주제, 활동 흐름, 성적, 방법, 깊이, 이어받은 기록과 이어진 기록(근거 줄, 상담 힌트), 기록 메모 |
| 탐구 방법 | 17가지 탐구 방법을 학기별, 교과군별로 센 표. 칸을 누르면 근거 문장이 열립니다. |
| 과학 탐구 과정 기능 | 2022 개정 과학과 교육과정을 참고해 재구성한 8가지 기능(문제 인식·가설 설정, 변인 통제·탐구 설계, 자료 수집·측정, 자료 변환·시각화, 자료 해석·분석, 결론 도출·평가·일반화, 모형 구성·활용, 의사소통·논증)을 학기별로 센 표 |
| 결손 지도 | 학기별 카드(기록 수, 쓴 방법, 수준 3 방법 비율, 평균 깊이, 아직 안 쓴 수준 3 방법)와 교과군별 기대 방법 가운데 비어 있는 것, 비어 있는 과학 탐구 기능, 다음 탐구 제안 문장 |
| 상담 노트 | 강점, 점검, 질문, 방향으로 나눈 상담 포인트(최대 14개)와 학생별, 기록별 메모 |
| 표현 사전 | 방법을 찾지 못한 활동 문장을 보고 학교에서 쓰는 표현을 사전에 더합니다. 내보내기와 가져오기를 지원하며 이 컴퓨터의 브라우저에만 저장됩니다. |
| 공통 | 이름 가리기, 작업 저장(.json)과 불러오기, 인쇄(A4 가로), 밝게/어둡게(설정은 브라우저에 저장) |

## 지원 브라우저

엔진의 정규식이 lookbehind(`(?<=…)`, `(?<!…)`)를 쓰므로 **Safari 16.4 이상**이 필요합니다. 크롬, 엣지 최신 버전을 권장합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # 타입체크 + 테스트 + 빌드
```

GitHub Pages 배포: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 `main`에 푸시할 때마다 `.github/workflows/deploy.yml`이 검사(타입체크, 테스트) 뒤 빌드해 올립니다. 다른 브랜치와 PR은 `.github/workflows/ci.yml`이 검사합니다.

## 폴더

```
src/engine/        분석 엔진(브라우저와 Node에서 모두 동작, DOM 의존 없음)
  types.ts         공용 타입
  dict/            어휘 사전: 탐구 방법 17종(methods.ts, methods.part1.ts 3단계, methods.part2.ts 1, 2단계),
                   성찰, 후속, 연결 패턴(patterns.ts), 관심 분야(fields.ts), 과학 탐구 과정 기능(skills.ts),
                   불용어(stop.ts), 과목, 교과군, 과목 계열(subjects.ts)
  parser/          NEIS 학생부 PDF 파서(셀 → 섹션 → 학생 데이터), 한 반 묶음 분리, 직접 입력
  pdf/             pdf.js로 글자와 표 선 추출
  analyze/         문장, 방법, 깊이, 주제, 관심 주제, 연결, 결손 분석, 상담 포인트
src/components/    화면(첫 화면, 계보도, 상세 창, 탐구 방법, 상담 노트, 표현 사전, 직접 입력)
src/lib/           파일 받기, pdf.js 불러오기, 표현 사전과 작업 파일 저장, 밝게/어둡게
src/state/         화면 상태
src/hooks/         분석 결과 캐시
src/fixtures/      가상 예시 학생
docs/DESIGN.md     설계 명세(규칙과 기준이 모두 적혀 있음)
docs/UI.md         화면 구현 계획
.github/workflows/ 검사(ci.yml)와 GitHub Pages 배포(deploy.yml)
```

## 알아 두실 점

- 스캔한 이미지 PDF는 글자 정보가 없어 읽을 수 없습니다. NEIS에서 PDF로 저장한 파일을 올려 주세요.
- 판단은 문장에 쓰인 표현을 근거로 합니다. 표현이 평범하면 낮게, 화려하면 높게 나올 수 있습니다. 계보도는 참고 자료이며 원문과 함께 보고 학생에게 직접 확인해 주세요.
- 창의적 체험활동은 학기 구분이 없어 같은 학년 세특과의 선후를 확정할 수 없습니다. 세특 본문이 창체 활동을 언급한 경우에만 순서를 정하고, 나머지는 근거 줄에 그렇게 적습니다.
- 작업 저장 파일(.json)과 인쇄물에는 학생 개인정보가 들어 있습니다. 학교 지침에 따라 보관하고 파기해 주세요. 이 저장소에 학생부 PDF나 작업 파일을 올리지 마세요.
- 브라우저에는 표현 사전과 밝게/어둡게 설정만 저장합니다. 학생 정보는 저장하지 않습니다.
