# NAVI 수시상담 워크북 → HTML 변환기

엑셀 워크북을 상담 중 빠르게 열람할 수 있는 **단일 HTML 파일**로 변환한다.
시트 구성을 탭으로 재현하고, 원본과 최대한 유사하게 유지하면서 열람성 위주로 디자인을 개선한다.

## 재현하는 것 (원본 충실도)

- 표시 시트 21개 전부를 같은 순서의 탭으로 (엑셀 탭 색상 그룹 유지: 안내/검색/환산·조견/전형 자료/학생 성적)
- 병합 셀(colspan/rowspan), 숨김 행·열 제외, 열 너비 비율, 표시 형식(%, 소수 자리)
- 시트별 구조: 안내문 시트는 문서로, 학생 정보·최저 산출 패널은 소형 그리드로, 대형 데이터는 표로
- 백분위조견표의 차트 이미지(EMF에서 변환한 PNG, data URI 내장)

## 개선하는 것

- **학생 자유 선택**: 상단 스트립에서 학생·모의고사 기준을 고르면 성적 칩, 검색,
  수능최저·논술 산출 패널, 등급변환표 안내가 전부 그 학생 기준으로 갱신
- **실시간 검색**(검색 탭): 숨김 `25점수계산기` 시트의 대학별 백분위 산출식(반영비율,
  영역 선택 규칙, 영어 등급 점수표)을 AST로 컴파일해 JS로 이식 — 원본 캐시값
  6,442행 전수 대조로 100% 일치 검증. 지역·계열·상하한·대학·모집단위 필터와
  내신 컷 5등급/9등급 전환, 차이값 정렬·색상 구분 지원
- 표 내 즉시 검색 + 주요 열(지역·대학명·계열·전형유형·전형명 등) 드롭다운 필터
- 머리글 행 고정 + 왼쪽 핵심 열 고정(엑셀 틀 고정과 동일 위치), '한 줄 보기' 토글
- 탭 전체 표시(줄바꿈), 지연 렌더링(250행 단위)으로 9,000행 시트도 즉시 열림
- 라이트/다크 테마 (자동·수동 전환), 줄무늬 행·호버 강조, 일관된 타이포그래피

등급 변환기 등 나머지 계산 기능은 저장 시점 스냅숏으로 표시하며 안내 문구를 붙인다.

## 사용법

```bash
# EMF 차트 이미지를 먼저 PNG로 변환해 둔 경우 (tools/excel-optimizer 참고)
python3 build_html.py 입력.xlsx 출력.html --images-dir png디렉터리
```

- `build_html.py` — 추출·변환 (openpyxl 필요)
- `template.html` — 디자인·렌더러 (탭/표/필터/테마), `/*__DATA__*/null` 자리에 데이터 주입

시트별 블록 구성은 `build_html.py`의 `CFG`에 선언되어 있다 (머리글 행, 데이터 시작 행,
열 범위, 고정 열 수). 워크북 양식이 바뀌면 `CFG`만 조정하면 된다.

> 생성된 HTML은 학생 개인정보(이름·성적)를 포함하므로 저장소에 커밋하지 않는다.
