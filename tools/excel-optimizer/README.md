# xlsx 용량 최적화 도구

NAVI 수시상담 워크북(8.3MB)이 무겁고 열기 느린 문제를 해결하기 위해 만든 범용 xlsx 최적화 스크립트.

## 진단 결과 (수시상담 NAVI 260814 기준)

| 항목 | 내용 |
|---|---|
| 원본 크기 | 8.33MB (압축 해제 시 50MB) |
| 최대 용량원 | 숨김 `data` 시트 16MB, `특별전형` 9.2MB, `수능최저` 6MB (실제 데이터라 축소 불가) |
| 제거 가능 | EMF 벡터 이미지 12개(6.7MB), calcChain.xml(1.6MB), 낮은 zip 압축률 |
| 결과 | **5.93MB (-29%)** — 데이터·수식·서식·차트·컨트롤 전부 동일 |

## 수행 항목

1. **EMF → PNG 변환** — 백분위조견표 시트의 차트 스냅숏 이미지를 원본 해상도 PNG로 재렌더링 (LibreOffice Draw 필요, 텍스트 위주 소형 이미지는 2배 해상도)
2. **calcChain.xml 제거** — Excel이 다음 열기에서 자동 재생성하는 캐시
3. **deflate 최고 압축(level 9) 재패킹**
4. **(선택) 틀 고정 추가** — `--freeze "시트명:셀"` 반복 지정

openpyxl 재저장은 폼 컨트롤·차트·메모·데이터 유효성 확장을 유실시키므로, ZIP/XML 수준에서만 수술적으로 수정한다.

## 사용법

```bash
python3 optimize_xlsx.py 입력.xlsx 출력.xlsx \
  --freeze "3월:E6" --freeze "5월:E6" --freeze "6월:E6" --freeze "7월:E6" \
  --freeze "9월:E6" --freeze "10월:E6" --freeze "11월:E6"
```

의존성: Python 3 표준 라이브러리 (+ EMF 변환 시 `libreoffice-draw`)

> 워크북 자체는 학생 개인정보(이름·성적)를 포함하므로 저장소에 커밋하지 않는다.
